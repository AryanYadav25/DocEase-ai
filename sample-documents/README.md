# Sample documents

Synthetic files with no personal or confidential data, generated for testing:

- `sample-library-terms.pdf` – 2-page PDF with a real text layer (fictional library membership terms)
- `sample-scanned-terms.pdf` – the same content rendered as images only (exercises OCR)
- `sample-notes-photo.png` – a "photo of notes" style image (biology notes)
- `sample-brief.docx` – short Word document
- `sample-plain-text.txt` – plain text version of the terms
